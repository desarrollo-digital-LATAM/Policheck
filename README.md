# POLICHECK

Landing estática para POLICHECK, servicios de evaluación poligráfica y orientación profesional de confianza.

## Desarrollo

```sh
npm install
npm run dev
```

## Comandos

| Comando | Acción |
| :--- | :--- |
| `npm run dev` | Inicia el servidor local |
| `npm run build` | Genera el sitio estático en `dist/` |
| `npm run preview` | Previsualiza la build de producción |

El formulario de contacto no almacena datos ni usa backend: construye una consulta y abre WhatsApp.
