- [ ] Publicar condiciones de atención revisadas por ALBERLIC.

## Límites actuales

- No se publican certificaciones, precios, garantías ni estadísticas no verificadas.
- No se ofrece asesoramiento legal.
- No se almacenan datos enviados desde el formulario.
