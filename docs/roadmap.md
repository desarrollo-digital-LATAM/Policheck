# Roadmap de POLICHECK

## Fase 1: Landing informativa

- [x] Presentar los servicios y el proceso general.
- [x] Centralizar las consultas comerciales en WhatsApp.
- [x] Publicar contenido educativo prudente sobre evaluación poligráfica.
- [x] Ofrecer un formulario sin almacenamiento de datos.

## Fase 2: Validación comercial

- [ ] Revisar las consultas recibidas y las necesidades más frecuentes.
- [ ] Validar el copy con las personas responsables del servicio.
- [ ] Incorporar información verificable sobre disponibilidad y requisitos, cuando exista.

## Fase 3: Información operativa

- [ ] Publicar condiciones de atención revisadas por POLICHECK.
- [ ] Añadir una política de privacidad cuando se implemente captación de datos propia.
- [ ] Considerar un canal de seguimiento solo si existe una necesidad operativa real.

## Límites actuales

- No se publican certificaciones, precios, garantías ni estadísticas no verificadas.
- No se ofrece asesoramiento legal.
- No se almacenan datos enviados desde el formulario.
